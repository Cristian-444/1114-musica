# 1114 Música

## Descripción

1114 Música es una aplicación web de biblioteca musical. Permitirá a los usuarios buscar, consultar, organizar y reproducir canciones.

El proyecto contará con una interfaz web, un servidor y una base de datos para administrar la información musical.

## Objetivo

Crear una biblioteca musical web funcional, moderna y fácil de utilizar.

## Funcionalidades principales

- Registro de usuarios.
- Inicio de sesión.
- Búsqueda de canciones.
- Búsqueda de artistas.
- Búsqueda de álbumes.
- Reproducción de canciones.
- Creación de playlists.
- Canciones favoritas.
- Historial de reproducción.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- Git
- GitHub

## Diseño

La aplicación tendrá:

- Tema oscuro.
- Colores morados y violetas.
- Diseño moderno.
- Diseño responsive.
- Menú lateral.
- Barra de búsqueda.
- Reproductor musical.
- Playlists.
- Artistas populares.
- Canciones recientes.
