# PRD - 1114 Música

## 1. Nombre del producto

**Nombre:** 1114 Música

## 2. Descripción

1114 Música será una aplicación web de biblioteca musical que permitirá a los usuarios buscar, consultar, organizar y reproducir canciones.

El sistema contará con un frontend, un servidor y una base de datos para administrar la información de usuarios, canciones, artistas, álbumes y playlists.

## 3. Objetivo general

Desarrollar una biblioteca musical web funcional, moderna y fácil de utilizar.

## 4. Usuarios

### Usuario

El usuario podrá:

- Registrarse.
- Iniciar sesión.
- Cerrar sesión.
- Buscar canciones.
- Buscar artistas.
- Buscar álbumes.
- Reproducir canciones.
- Crear playlists.
- Agregar canciones a favoritos.
- Consultar su historial.

### Administrador

El administrador podrá:

- Gestionar usuarios.
- Agregar canciones.
- Editar canciones.
- Eliminar canciones.
- Agregar artistas.
- Editar artistas.
- Eliminar artistas.
- Agregar álbumes.
- Editar álbumes.
- Eliminar álbumes.
- Gestionar géneros musicales.

## 5. Funcionalidades principales

### Autenticación

- Registro de usuarios.
- Inicio de sesión.
- Cierre de sesión.

### Canciones

Cada canción tendrá:

- Nombre.
- Artista.
- Álbum.
- Género.
- Duración.
- Imagen.
- Archivo o recurso de reproducción.

### Artistas

Cada artista tendrá:

- Nombre.
- Imagen.
- Descripción.
- Canciones.
- Álbumes.

### Álbumes

Cada álbum tendrá:

- Nombre.
- Artista.
- Imagen.
- Año.
- Canciones.

### Playlists

Los usuarios podrán:

- Crear playlists.
- Cambiar el nombre.
- Agregar canciones.
- Eliminar canciones.
- Eliminar playlists.

### Favoritos

Los usuarios podrán:

- Agregar canciones a favoritos.
- Eliminar canciones de favoritos.
- Consultar sus canciones favoritas.

### Historial

El sistema registrará las canciones reproducidas por cada usuario.

### Buscador

El usuario podrá buscar:

- Canciones.
- Artistas.
- Álbumes.
- Géneros.

### Reproductor

El reproductor permitirá:

- Reproducir canciones.
- Pausar canciones.
- Cambiar de canción.
- Avanzar.
- Retroceder.
- Controlar el volumen.
- Mostrar el progreso de reproducción.

## 6. Diseño

La aplicación tendrá un diseño oscuro con tonos morados y violetas.

La página principal contará con:

- Menú lateral.
- Logo.
- Barra de búsqueda.
- Perfil del usuario.
- Playlists recientes.
- Artistas populares.
- Canciones recientes.
- Reproductor musical.

## 7. Requisitos generales

El sistema deberá:

1. Permitir registrar usuarios.
2. Permitir iniciar sesión.
3. Permitir cerrar sesión.
4. Permitir buscar contenido.
5. Mostrar canciones.
6. Mostrar artistas.
7. Mostrar álbumes.
8. Permitir reproducir canciones.
9. Permitir crear playlists.
10. Permitir guardar favoritos.
11. Registrar el historial.
12. Contar con funciones administrativas.
13. Ser responsive.
14. Estar conectado a una base de datos.

## 8. Tecnologías

El proyecto utilizará:

- HTML5.
- CSS3.
- JavaScript.
- Node.js.
- Express.js.
- MySQL.
- Git.
- GitHub.

## 9. Resultado esperado

Obtener una aplicación web de biblioteca musical funcional, moderna y organizada, conectada a un servidor y una base de datos.

Los usuarios podrán consultar y reproducir música, crear playlists, guardar favoritos y consultar su historial.
